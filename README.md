# My Portfolio

A simple personal portfolio website created as part of the Programming for Web Development-I Laboratory.

## About the Project

This project introduces my portfolio using HTML. It contains information about me, my skills, and my projects.

## Features

- Semantic HTML structure
- About Me section
- Skills section
- Projects section
- Header and footer

## Technologies Used

- HTML5
- Git
- GitHub

## How to Run

1. Clone or download this repository.
2. Open the `My-Portfolio` folder.
3. Open `index.html` in your web browser.

## Git Workflow

This project uses Git for version control.

- Main branch: `main`
- Feature branch: `feature-about-section`
