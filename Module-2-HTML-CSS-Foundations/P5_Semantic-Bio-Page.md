# P5: Semantic Bio Page

## Objective
To create a personal biography webpage using semantic HTML elements.

## HTML Elements Used
- `<header>` – Defines the page heading.
- `<main>` – Contains the main page content.
- `<section>` – Groups related information.
- `<h1>` and `<h2>` – Define headings.
- `<p>` – Displays paragraphs.
- `<ul>` and `<li>` – Display hobbies as a list.
- `<footer>` – Defines the page footer.

## Features
- Personal introduction
- Education details
- Hobbies
- Personal goals
- Semantic HTML structure

## Result
Successfully created and opened a semantic personal bio webpage in the browser.
