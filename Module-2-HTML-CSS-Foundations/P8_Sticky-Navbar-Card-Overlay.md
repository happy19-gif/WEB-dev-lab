# P8: Sticky Navbar and Card Overlay Using CSS Positioning

## Objective
To create a sticky navigation bar and a project card with an overlay using CSS positioning properties.

## Tools Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## Implementation

### 1. Sticky Navigation Bar
Used `position: sticky`, `top: 0`, and `z-index: 1000` to keep the navigation bar visible at the top while scrolling.

### 2. CSS Flexbox
Used Flexbox properties to arrange the portfolio title and navigation links horizontally.

### 3. Card Positioning
Used `position: relative` on the project card to establish a positioning context for the overlay.

### 4. Card Overlay
Used `position: absolute` to place the overlay at the bottom of the project image.

### 5. Hover Effect
Used `opacity` and `transition` to display the overlay smoothly when the mouse moves over the card.

## Result
Successfully created a webpage with a sticky navigation bar and a project card overlay. Tested scrolling, navigation links, and the hover effect in the browser.

## Conclusion
Learned how to use CSS positioning properties such as `sticky`, `relative`, and `absolute` to create interactive webpage layouts.
