# P7: Design Tokens and Typography System in CSS

## Objective
To create a reusable design system using CSS custom properties (design tokens) and establish consistent typography, colors, spacing, and styling across a webpage.

## Tools Used
- HTML
- CSS
- Visual Studio Code
- Web Browser

## Implementation

### 1. Design Tokens
Used the CSS `:root` selector to define reusable variables for:
- Primary and secondary colors
- Background and surface colors
- Text and muted colors
- Font family and font sizes
- Spacing values
- Border radius

### 2. Global Styles
Applied universal `box-sizing`, page margin, padding, font family, line height, text color, and background color.

### 3. Typography System
Styled headings and paragraphs using reusable font-size and color variables.

### 4. Card Styling
Created a reusable card design with background color, padding, margin, and rounded corners.

### 5. Button Styling
Styled buttons with a primary background color, white text, rounded corners, and pointer cursor.

## Result
Successfully created a reusable CSS design-token system and typography styles. Linked the stylesheet to the P6 portfolio page and verified that the styles display correctly in the browser.

## Conclusion
Learned how CSS custom properties improve consistency, readability, and maintainability when designing webpages.
