# P11: Newspaper-Style Three-Column Layout Using CSS Grid

## Objective
To create a newspaper-style webpage with three columns using CSS Grid and make the layout responsive for different screen sizes.

## Tools Used
- HTML5
- CSS3
- Visual Studio Code
- Safari Browser

## Implementation

### 1. Newspaper Header
Created a newspaper title and subtitle using semantic HTML elements.

### 2. Navigation Bar
Used Flexbox to arrange navigation links horizontally.

### 3. CSS Grid Layout
Used `display: grid` and `grid-template-columns: repeat(3, 1fr)` to create three equal-width columns.

### 4. News Articles
Created three article sections:
- Technology
- Education
- Sports

Each article contains an image, heading, and paragraph.

### 5. Responsive Design
Used media queries to change the layout:
- Desktop: Three columns.
- Tablet: Two columns.
- Mobile: One column.

## Result
Successfully created a newspaper-style webpage using CSS Grid. Tested the three-column, two-column, and single-column layouts.

## Conclusion
Learned how to use CSS Grid to create structured multi-column layouts and responsive webpages.
