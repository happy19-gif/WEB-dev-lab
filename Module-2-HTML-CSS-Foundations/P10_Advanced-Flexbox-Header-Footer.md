# P10: Portfolio Header and Footer with Advanced Flexbox

## Objective
To design a portfolio webpage with a flexible header and footer using advanced CSS Flexbox properties.

## Tools Used
- HTML5
- CSS3
- Visual Studio Code
- Safari Browser

## Implementation

### 1. Header Layout
Used `display: flex`, `justify-content: space-between`, and `align-items: center` to arrange the logo, navigation links, and Hire Me button.

### 2. Navigation Styling
Used Flexbox properties such as `gap`, `flex-wrap`, and hover effects to organize navigation links.

### 3. Footer Layout
Created three footer sections:
- About
- Quick Links
- Contact

Used `display: flex`, `flex-wrap`, and `flex: 1 1 200px` to arrange the sections.

### 4. Footer Bottom
Used `flex-basis: 100%` to place the copyright section on a separate full-width row.

### 5. Responsive Design
Used a media query at 768px to arrange the header and footer vertically on smaller screens.

## Result
Successfully created a portfolio webpage with an advanced Flexbox header and footer. Tested the desktop and mobile layouts.

## Conclusion
Learned how to use advanced Flexbox properties to create flexible, organized, and responsive webpage layouts.
