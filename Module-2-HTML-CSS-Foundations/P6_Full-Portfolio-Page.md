# P6: Full Portfolio Page Structure in Semantic HTML

## Objective
To create a complete portfolio webpage using semantic HTML elements.

## Sections Created
1. Header with name and navigation.
2. Home section with an introduction.
3. About Me section.
4. Skills section.
5. Projects section using article elements.
6. Contact section.
7. Footer with copyright information.

## HTML Elements Used
- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<h1>` to `<h3>`
- `<p>`
- `<ul>` and `<li>`
- `<a>`

## Result
Successfully created and tested a complete portfolio webpage with semantic HTML structure and working navigation links.
