# P9: Responsive Navbar and Card Grid Using Flexbox

## Objective
To create a responsive navigation bar and project card layout using CSS Flexbox that adapts to different screen sizes.

## Tools Used
- HTML5
- CSS3
- Visual Studio Code
- Safari Browser

## Implementation

### 1. Responsive Navigation Bar
Used `display: flex`, `justify-content`, and `align-items` to arrange the portfolio title and navigation links.

### 2. Flexbox Card Grid
Used `display: flex`, `flex-wrap: wrap`, and `gap` to arrange project cards in a flexible layout.

### 3. Card Styling
Designed project cards with background colors, padding, rounded corners, and box shadows.

### 4. Media Queries
Used CSS media queries at 768px and 480px to adjust the navbar and cards for tablet and mobile screens.

### 5. Hover Effects
Used the CSS `transform` and `transition` properties to create a smooth card hover effect.

## Result
Successfully created a responsive portfolio webpage. Tested the desktop and mobile layouts using Safari Responsive Design Mode.

## Conclusion
Learned how to use CSS Flexbox and media queries to build responsive navigation bars and card layouts.
