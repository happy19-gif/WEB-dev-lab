# P12: Portfolio Projects Grid with Advanced CSS Grid

## Aim
To create a responsive portfolio projects section using advanced CSS Grid properties.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Media Queries

## Description
This practical demonstrates how CSS Grid can be used to arrange portfolio project cards in multiple columns and rows.

The page contains five project cards. Each card displays a project image, title, description, and technology label.

## CSS Grid Concepts Used

1. `display: grid` – Creates a grid layout.
2. `grid-template-columns` – Defines the number and size of columns.
3. `grid-auto-rows` – Controls automatically generated row sizes.
4. `gap` – Adds spacing between grid items.
5. `grid-column: span 2` – Makes the featured project occupy two columns.
6. `grid-row: span 2` – Makes the featured project occupy two rows.
7. Media queries – Adjust the layout for tablets and mobile devices.

## Responsive Design
- Desktop: Three-column layout with a larger featured project.
- Tablet: Two-column layout.
- Mobile: Single-column layout.

## Output
A responsive portfolio projects grid containing five project cards, with one featured card occupying additional grid space.

## Conclusion
Successfully created a responsive portfolio projects layout using advanced CSS Grid properties and media queries.
